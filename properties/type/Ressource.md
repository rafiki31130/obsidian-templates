## Définition

**Ressource** utile : article, astuce, contenu glané pour plus tard.

## Caractéristiques

Rangée dans `pages/3. Ressources/`.

## Propriétés

Template d'application : `templates/type_Props-Ressource.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Ressource`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Une **Reference** est maintenue comme source de vérité ; une Ressource est un contenu à consulter.
