## Définition

**Entretien technique** : échange avec un interlocuteur sur un sujet technique (entretien de recrutement, point d'expertise, revue avec un éditeur…).

## Caractéristiques

Trace la date, les participants (`people:`), les questions abordées et les conclusions.

## Propriétés

Template d'application : `templates/type_Props-EntretienTech.md` (généré par `Script_GenerateTypeTemplates`).

- `type: EntretienTech`
- `domain:` liens vers le ou les Topics concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **Meeting** est une réunion d'équipe générale ; un EntretienTech est centré sur l'évaluation ou l'approfondissement technique.
