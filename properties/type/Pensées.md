## Définition

**Réflexion personnelle** : idée, opinion, prise de recul.

## Caractéristiques

Contenu libre et subjectif, sans objectif d'action.

## Propriétés

Template d'application : `templates/type_Props-Pensées.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Pensées`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **Concepts** est une connaissance objective ; Pensées est un point de vue personnel.
