## Définition

**Réflexion personnelle** : idée, opinion, prise de recul.

## Caractéristiques

Contenu libre et subjectif, sans objectif d'action.

## Propriétés

Template d'application : `templates/type_Pensées.md`.

- `type: Pensées`
- `date:` lien vers le journal du jour de création (`"[[YYYY-MM-DD]]"`)
- `topic:` lien(s) vers le ou les Topics concernés

Corps : aucun (page libre, section Notes).

## Différence avec les autres types

Un **Concepts** est une connaissance objective ; Pensées est un point de vue personnel.
