## Définition

**Journal de bord** chronologique d'un sujet précis (entrées datées successives).

## Caractéristiques

Chaque entrée est datée ; le contenu s'accumule dans le temps.

## Propriétés

Template d'application : `templates/type_Props-Log.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Log`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Le **Journal** suit une journée ; un Log suit un sujet sur plusieurs jours.
