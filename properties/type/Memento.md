## Définition

**Aide-mémoire** court : commandes, raccourcis, infos à retrouver vite.

## Caractéristiques

Format condensé, orienté consultation rapide.

## Propriétés

Template d'application : `templates/type_Props-Memento.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Memento`
- `domain:` liens vers le ou les Topics concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Une **Documentation** est exhaustive ; un Memento ne garde que l'essentiel.
