## Définition

**Incident** : perturbation imprévue d'un service ou d'un système.

## Caractéristiques

Décrit symptômes, impact, chronologie, cause et résolution.

## Propriétés

Template d'application : `templates/type_Props-Incident.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Incident`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **Changement** est planifié ; un Incident est subi.
