## Définition

**Étude** ou analyse préalable : comparatif, faisabilité, recherche avant décision.

## Caractéristiques

Se conclut par une recommandation ou une décision.

## Propriétés

Template d'application : `templates/type_Props-Etude.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Etude`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **Projet** exécute ; une Etude prépare la décision de lancer (ou non).
