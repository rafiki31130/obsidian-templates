## Définition

**Étude** ou analyse préalable : comparatif, faisabilité, recherche avant décision.

## Caractéristiques

Se conclut par une recommandation ou une décision.

## Propriétés

Template d'application : `templates/type_Etude.md`.

- `type: Etude`
- `topic:` lien(s) vers le ou les Topics concernés

Corps : Question · Options (tableau avantages / inconvénients) · Conclusion.

## Différence avec les autres types

Un **Projet** exécute ; une Etude prépare la décision de lancer (ou non).
