## Définition

Information de **référence** stable, consultée régulièrement (liste, spécifications, tableau de valeurs).

## Caractéristiques

Contenu factuel, mis à jour ponctuellement.

## Propriétés

Template d'application : `templates/type_Props-Reference.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Reference`
- `domain:` liens vers le ou les Topics concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **Topic** rassemble tout ce qui touche à un sujet ; une Reference est une source de vérité maintenue.
