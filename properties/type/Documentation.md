## Définition

**Documentation** technique ou fonctionnelle d'un système, d'un outil ou d'une application.

## Caractéristiques

Décrit l'existant : architecture, configuration, fonctionnement.

## Propriétés

Template d'application : `templates/type_Props-Documentation.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Documentation`
- `domain:` liens vers le ou les Topics concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Une **Procedure** est un pas-à-pas pour réaliser une action ; la Documentation décrit l'état du système.
