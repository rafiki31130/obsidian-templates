## Définition

**Compte-rendu de réunion** : participants, ordre du jour, décisions, actions.

## Caractéristiques

Les participants vont dans `people:` ; les actions en tâches `#Todo`.

## Propriétés

Template d'application : `templates/type_Props-Meeting.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Meeting`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **EntretienTech** est un échange technique ciblé ; un Meeting est une réunion de travail.
