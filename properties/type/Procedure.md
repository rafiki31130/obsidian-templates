## Définition

**Mode opératoire** pas à pas pour réaliser une action reproductible.

## Caractéristiques

Étapes numérotées, prérequis, vérifications.

## Propriétés

Template d'application : `templates/type_Props-Procedure.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Procedure`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Une **Documentation** décrit un système ; une Procedure dit comment agir dessus.
