## Définition

**Domaine** de responsabilité continu, sans date de fin (Santé, Maison, Comptes, PRO…).

## Caractéristiques

Rangé dans `pages/2. Domaines/`, créé via le template `Page-Domaine`. Sert de parent aux projets et notes du domaine.

## Propriétés

Template d'application : `templates/type_Props-Domain.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Domain`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **Projet** se termine ; un Domaine est entretenu en permanence.
