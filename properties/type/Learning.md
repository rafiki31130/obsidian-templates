## Définition

**Apprentissage** en cours : formation, cours, certification, montée en compétence.

## Caractéristiques

Contient objectifs, supports, notes de cours et progression.

## Propriétés

Template d'application : `templates/type_Props-Learning.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Learning`
- `domain:` liens vers le ou les Topics concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **Concepts** est la connaissance acquise ; un Learning est le parcours pour l'acquérir.
