## Définition

**Changement** planifié sur un système (mise en production, migration, modification de configuration).

## Caractéristiques

Décrit le périmètre, le plan de mise en œuvre, le plan de retour arrière et le résultat.

## Propriétés

Template d'application : `templates/type_Props-Changement.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Changement`
- `domain:` liens vers le ou les domaines concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Un **Incident** subit une perturbation imprévue ; un Changement est voulu et planifié.
