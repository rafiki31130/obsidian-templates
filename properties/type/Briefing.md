## Définition

Synthèse **quotidienne** préparée pour démarrer la journée : agenda, tâches en retard, points d'attention.

## Caractéristiques

Rangée dans `briefings/`, nommage `YYYY-MM-DD @ Briefing`.

## Propriétés

Template d'application : `templates/type_Props-Briefing.md` (généré par `Script_GenerateTypeTemplates`).

- `type: Briefing`
- `domain:` liens vers le ou les Topics concernés
- `people:` liens vers les personnes concernées
- `rating:` note (entier)
- `tags:`

## Différence avec les autres types

Le **Journal** est la note du jour écrite au fil de l'eau ; le Briefing est une synthèse préparée en amont.
