## Les détails qui rendent la méthode efficace

### 1. Le geste à automatiser : note → modèle → liens

1. Créer une **note unique**, préfixée par `YYYY-MM-DD HHmm` dans la configuration montrée.
2. Ajouter un **titre descriptif** : le nom doit permettre de retrouver la note.
3. Insérer le **modèle adapté**, par exemple Meeting, People, Movie ou Evergreen.
4. Compléter les propriétés utiles, avec des **liens vers les personnes, catégories ou sujets** plutôt que seulement du texte.
5. Écrire et relier les premières mentions importantes. Les vues et les liens entrants deviennent les chemins de retour.[1]

**Attention :** la date de création, les tags et le modèle Journal préremplis viennent du coffre de démonstration et de ses réglages. Ce n’est pas un comportement à supposer dans n’importe quel coffre neuf.[1]

### 2. Les raccourcis montrés dans la vidéo

| Action | Windows | macOS | Statut dans la démonstration |
|---|---|---|---|
| Ouvrir le sélecteur rapide | `Ctrl + O` | `Cmd + O` | Raccourci utilisé pour retrouver notes et catégories. |
| Créer une note unique | `Alt + Shift + N` | `Option + Shift + N` | Attribution proposée par Karlos dans les réglages. |
| Insérer un modèle | `Alt + Shift + T` | `Option + Shift + T` | Attribution proposée par Karlos. |
| Ouvrir la note du jour | `Alt + Shift + D` | `Option + Shift + D` | Attribution proposée par Karlos. |
| Ajouter un lien interne | `Alt + Shift + L` | `Option + Shift + L` | Attribution proposée par Karlos ; alternative à taper `[[...]]`. |
| Revenir / avancer dans la navigation | `Ctrl + Alt + ← / →` | `Cmd + Option + ← / →` | Présenté pour naviguer entre les notes déjà visitées. |

Les attributions proposées se font dans **Réglages → Raccourcis clavier**. Elles ne remplacent pas automatiquement celles déjà choisies dans le coffre.[1]

### 3. Le vrai « trick » : les propriétés sont aussi des liens

- **Personne :** dans une rencontre, renseigner `[[Aisha]]` comme participante, puis ouvrir sa fiche directement depuis cette propriété.
- **Vue contextuelle :** le modèle People de la démonstration affiche les rencontres liées à cette personne. Le modèle Author ajoute une vue sur ses livres.
- **Liens entrants :** ouvrir le panneau des backlinks pour retrouver les notes qui mentionnent la fiche, même si aucun lien retour n’a été écrit dans son corps.
- **Cibles inexistantes :** laisser les liens en attente jusqu’au jour où la note mérite d’être créée. Les liens gardent une trace du cheminement initial.[1]

**Exemple illustratif créé pour cette fiche :** une note de rencontre pointe vers `[[Camille]]` et vers `[[Écrire pour comprendre]]`. La première devient une fiche de personne ; la seconde peut devenir une note Evergreen réutilisée ailleurs.

### 4. Propriétés et modèles : les manipulations utiles

- Cliquer sur l’icône d’une propriété pour adapter son **type**, par exemple **Nombre** pour une note ou un niveau scolaire.
- **Composer les modèles** plutôt que multiplier leurs combinaisons : une même personne peut être aussi autrice.
- Si une date de modèle affiche l’avertissement montré dans la vidéo, Karlos utilise la mise à jour proposée puis le calendrier pour remettre la bonne date. Il s’agit d’un problème observé dans sa démonstration, pas d’un bug général vérifié aujourd’hui.[1]

**Complément de l’article original :** réutiliser les mêmes noms de propriétés entre catégories, garder des noms courts et préférer une propriété liste si plusieurs valeurs deviennent possibles. Ce conseil complète les manipulations expliquées dans la vidéo.[2]

### 5. Noter de 1 à 7

La vidéo montre les deux extrêmes et l’usage de `rating` sur une œuvre ou même un événement personnel. La vue Ratings permet de retrouver les éléments notés.[1]

Les niveaux intermédiaires sont précisés dans l’article original : **7** exceptionnel ; **6** excellent, à renouveler ; **5** agréable sans justifier un détour ; **4** acceptable à défaut de mieux ; **3** mauvais ; **2** à éviter activement ; **1** profondément négatif.[2]

### 6. Le rythme de prise de notes

| Fréquence               | Geste                                                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Au fil de la journée    | Capturer une pensée ou un événement dans une note distincte, avec titre, liens et modèle si utile.                                         |
| Tous les quelques jours | Relire les captures récentes et compiler les idées ou évolutions qui ressortent. Ce n’est pas une cadence rigide de trois ou quatre jours. |
| Chaque semaine          | Garder une liste simple de choses à faire, sous forme de checklist Markdown. Aucun système sophistiqué n’est requis dans l’exemple.        |
| Chaque mois             | Relire les compilations et en tirer une synthèse de niveau supérieur.                                                                      |
| Tous les quelques mois  | Utiliser « Ouvrir une note aléatoire », suivre les liens et redécouvrir d’anciennes idées.                                                 |
| Chaque année            | Relire les synthèses mensuelles et prendre du recul, avec les « 40 questions » citées par Steph Ango.                                      |

L’essentiel est la **relecture active** : retrouver des motifs dans ses pensées et transformer des captures isolées en compréhension.[1]


## À reprendre sans bouleverser mon coffre

Ces pistes sont une adaptation à l’existant, pas une modification déjà appliquée :

- **Liens internes :** enrichir les notes au moment d’écrire, même si certaines cibles n’existent pas encore.
- **Modèles :** compléter ceux qui existent plutôt qu’importer toute une organisation concurrente.
- **Propriétés :** respecter les conventions du coffre ; créer un nouveau champ seulement s’il sert une recherche ou une vue utile.
- **Relecture :** commencer par une courte revue des captures récentes avant d’ajouter de l’outillage.
- **Journal et tâches :** conserver `journals/`, les entrées de journal et le suivi des tâches actuels. La page quotidienne vide et la simple checklist hebdomadaire de Kepano sont ses choix, pas des prérequis.

Raccourcis déjà consignés dans [[Obsidian tweaks et hotkeys obsidian]] : `Ctrl + O` pour le sélecteur rapide et `Alt + D` pour insérer un modèle. Conserver les attributions existantes plutôt que reprendre celles de Karlos à l’aveugle. **Aucun raccourci ni réglage n’a été modifié.**
