
Identifie le sous-type de fiche dans le schéma CPT. Une seule valeur est portée par la propriété type.

## Type et rôle

- Propriété : `type`.
- Type attendu : **Texte**.
- Schéma : [[r_templates/resources/bases_properties/CPT/CPT|CPT]].
- Type natif actuellement enregistré : Texte.

Utilisée par : `Comptes.Budgets`, `Comptes.Charges`, `Comptes.Decomptes`.
