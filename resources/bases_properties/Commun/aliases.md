
Noms alternatifs de la fiche utilisés pour la recherche et les liens.

## Type et rôle

- Propriété : `aliases`.
- Type attendu : **Liste**.
- Schéma : [[r_templates/resources/bases_properties/Commun/Commun|Commun]].
- Type natif actuellement enregistré : Liste.

Définition commune aux schémas. Elle n’est pas recopiée dans chaque base.

## Saisie

Les modèles et les règles de saisie du schéma définissent ce champ. Les valeurs personnelles restent dans les fiches de données : elles ne sont ni collectées ni publiées dans le catalogue, même à titre d’exemples. Aucune fiche de valeur utilisateur n’est générée.
