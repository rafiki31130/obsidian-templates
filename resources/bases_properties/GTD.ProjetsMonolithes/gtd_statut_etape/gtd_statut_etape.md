
Statut de l’étape au sprint. Le blocage est décrit dans le corps de la note.

## Type et rôle

- Propriété : `gtd_statut_etape`.
- Type attendu : **Texte**.
- Base : [[r_templates/resources/bases_properties/GTD.ProjetsMonolithes/GTD.ProjetsMonolithes|GTD.ProjetsMonolithes]].

## Valeurs prévues

- [[r_templates/resources/bases_properties/GTD.ProjetsMonolithes/gtd_statut_etape/1_a_preparer|1_a_preparer]] — Résultat identifié, prochaines actions encore à préparer.
- [[r_templates/resources/bases_properties/GTD.ProjetsMonolithes/gtd_statut_etape/2_prete|2_prete]] — Prochaines actions écrites, premier geste connu.
- [[r_templates/resources/bases_properties/GTD.ProjetsMonolithes/gtd_statut_etape/3_en_cours|3_en_cours]] — Travail engagé ; au moins un projet parent doit être actif.
- [[r_templates/resources/bases_properties/GTD.ProjetsMonolithes/gtd_statut_etape/4_bloquee|4_bloquee]] — Travail bloqué ; décrire la cause dans la page.
- [[r_templates/resources/bases_properties/GTD.ProjetsMonolithes/gtd_statut_etape/8_faite|8_faite]] — Résultat de l’étape atteint. Sur un monolithe, revoir aussi le statut projet.
- [[r_templates/resources/bases_properties/GTD.ProjetsMonolithes/gtd_statut_etape/9_abandonnee|9_abandonnee]] — Étape explicitement abandonnée.

## Création

Valeur(s) prévue(s) par le ou les modèles : `'1_a_preparer'`.
