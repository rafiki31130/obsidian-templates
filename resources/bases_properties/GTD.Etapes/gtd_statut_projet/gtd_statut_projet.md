
Statut du projet au portefeuille ; un monolithe possède aussi un statut d’étape indépendant.

## Type et rôle

- Propriété : `gtd_statut_projet`.
- Type attendu : **Texte**.
- Base : [[r_templates/resources/bases_properties/GTD.Etapes/GTD.Etapes|GTD.Etapes]].

## Valeurs prévues

- [[r_templates/resources/bases_properties/GTD.Etapes/gtd_statut_projet/1_en_attente|1_en_attente]] — Projet identifié, pas encore engagé.
- [[r_templates/resources/bases_properties/GTD.Etapes/gtd_statut_projet/2_actif|2_actif]] — Projet choisi dans la capacité actuelle ; compte dans le plafond de cinq actifs.
- [[r_templates/resources/bases_properties/GTD.Etapes/gtd_statut_projet/3_en_pause|3_en_pause]] — Engagement suspendu, contexte conservé ; ne compte plus comme actif.
- [[r_templates/resources/bases_properties/GTD.Etapes/gtd_statut_projet/8_termine|8_termine]] — Critère de fin atteint ; toutes les étapes sont faites ou abandonnées.
- [[r_templates/resources/bases_properties/GTD.Etapes/gtd_statut_projet/9_abandonne|9_abandonne]] — Projet explicitement abandonné.

## Création

Valeur(s) prévue(s) par le ou les modèles : `'1_en_attente'`.
